Manutenção Master

O backup inclui código, templates, static, migrations, banco, logs e todos os uploads (inclusive os ZIPs/TXTs originais do WhatsApp), além do cofre de segredos (chave de assinatura e cookie do Strava). Ficam fora apenas cache, temporários, venv e git (o venv é recriável a partir do requirements.txt).
Na restauração o cofre só volta se o servidor estiver sem um — assim uma restauração de rotina não troca a chave em uso nem desloga ninguém.

Deixar o sistema enxuto

Libera espaço que não serve mais para nada: a imagem de mensagens que já foram entregues (o registro do envio continua), itens de fila entregues há mais de 60 dias e acompanhamentos de trabalhos já concluídos. Não apaga km, atividade, atleta, ranking nem patrocinador, e não encosta em trabalho que ainda está rodando. Roda sozinha uma vez por dia; este botão é para quando você quiser o resultado agora.

Restaurar Backup

Restaura banco de dados, uploads e imagens a partir de um backup da pasta Backups do servidor. O código da aplicação não é alterado. Após concluir, reinicie o perfil web no DSM.
